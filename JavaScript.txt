Operators:

1. Arithmetic -> =, -, *, /, %, **

2. comparison -> >, <, <=, >=, ===, !==, ==
	are usually used to compare two values, result is always a Boolean value either true, or false
== -> checks the values are equal or not.
ex: 10 == "10" -> true
=== -> checks the values are equal and the type of it.
ex: 10==="10" -> false
!== -> checks whether the values are not equal
ex: 10!== 20 -> true

3. Logical -> &&, ||, !
	used to combine or reverse condition. they return true or false.

4. assignment -> =, +=, -=, *=, /=, %=

Advance array methods

1. map() -> create a new array populated with the result of calling a provided function on every element.

2. filter() -> used to create new array containing only elements that satisfy the condition.

3. reduce() -> used to reduce all array elements into a single value

4. find() -> find the first element and it returns it which satisfy the condition, if no element matches it returns undefined.
